# TabPrefix 2.5.0

- «Таб мечты»: палитра текстовых элементов, player list и картинок, drag/drop в 80 ячеек, touch/tap, настройки блока, header/footer drop zones, undo/redo и общее сохранение/JSON.
- «Глифы и пак»: пиксельный PNG-редактор, загрузка изображений/GIF, авторизованный каталог постоянных assets, сборка и скачивание pack, переход в групповой prefix editor.
- 1.12.x: настоящий Unicode pack format 3 с сохранением исходных метрик/неназначенных символов, bounded hash-verified извлечение fonts из официального client JAR, кэш и ручной импорт `glyph_sizes.bin`. PNG/GIF включаются после загрузки; размер одного глифа ограничен старым renderer.
- Sidebar обновляет существующие objective/teams при смене Bukkit-обёрток. Строки заполняются до показа, scores сохраняют порядок. Чужой objective не удаляется.
- Blank score number format с 1.20.3 через Paper API либо доступный native setter; фактический статус в doctor. На старых клиентах полное скрытие требует мода.
- «Экран»: до 12 TEXT/IMAGE блоков в TITLE/SUBTITLE/ACTION_BAR, условия, frames/scroll, heartbeat и отдельное личное отключение. Произвольные координаты требуют клиентского мода, который не входит в версию.
- Studio получил единые SVG-значки, новые адаптивные панели и честные подсказки по возможностям 1.12/скорборда.
- Сохраняются SQLite schema 3, старые документы, UUID и назначения glyphs. Отдельная регистрация изображения не изменяет префиксы LuckPerms/групп. Minecraft fonts не включены в поставку.

Инструкции: [DREAM-TAB.md](DREAM-TAB.md). Покрытие и пределы проверок: [VALIDATION.md](VALIDATION.md).
