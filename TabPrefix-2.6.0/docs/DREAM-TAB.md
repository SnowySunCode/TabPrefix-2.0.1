# «Таб мечты», глифы и экран — 2.6.0

Откройте `/lptab studio`, оставаясь в игре. Для оформления, изображений и resource pack нужно `tabprefix.design`. Для своих переключателей — `tabprefix.settings`. API повторно проверяет онлайн-состояние и права.

## Макет без ручной разметки

1. Перейдите в «Таб мечты». При необходимости очистите 80 ячеек: действие можно отменить.
2. Перетащите элемент из палитры: свой текст, игрок, список игроков, онлайн, здоровье, пинг, мир, время, разделитель или пустая ячейка. «Список игроков» заполняет оставшуюся часть столбца, сохраняя уже занятые ячейки.
3. Нажмите на ячейку и настройте текст, цвет, кадры/прокрутку или позицию игрока в общем списке. Перетаскивание двух ячеек меняет их местами. Заголовок и footer принимают текстовые элементы.
4. Перетащите картинку из каталога в ячейку. При отсутствии принятого pack показывается запасной текст блока.
5. Нажмите «Применить к серверу». До этого макет остаётся черновиком. Undo/redo, общий JSON-импорт/экспорт и защита от конкурирующего сохранения работают как в обычном Studio.

На телефоне можно перетаскивать элементы либо нажать на элемент и затем на нужное место. Геометрия Minecraft TAB фиксирована: четыре столбца по 20 строк. Позиция игрока относится к отсортированному видимому списку, а не к UUID.

## Свой глиф и resource pack

Вкладка «Глифы и пак» содержит пиксельный холст 16×16, выбор цвета, ластик, очистку и рисование буквы/знака. «Создать глиф» отправляет PNG в общий каталог. Можно загрузить PNG/JPEG/GIF, скачать рисунок как PNG, пересобрать pack и скачать ZIP. GIF использует постоянные коды каждого обработанного кадра.

Загрузка сразу сохраняет asset и назначает codepoints в существующей SQLite-базе. Это отдельное действие от применения макета. Идентичный файл и настройки повторно используют тот же asset. Коды не освобождаются при удалении блока: это сохраняет смысл старых текстов и ревизий pack. Каталог выводится страницами по 24 изображения; эскизы доступны только с авторизованной design-сессией.

Для группового графического префикса укажите группу и откройте её редактор. Нужны `tabprefix.webeditor` и, при выборе другой группы, `tabprefix.prefix.manage`. Применение группового префикса проходит существующий редактор/код; размещение картинки на экране не меняет префиксы групп и узлы LuckPerms.

## Настоящий pack 1.12.x

Клиент 1.12 не умеет современные bitmap font providers. Pack format 3 использует:

| Файл внутри ZIP | Назначение |
|---|---|
| `assets/minecraft/font/glyph_sizes.bin` | Исходные 65 536 байт ширин с изменением только назначенных глифов |
| `assets/minecraft/textures/font/unicode_page_XX.png` | Unicode-страницы 256×256, 16×16 пикселей на ячейку |
| `tabprefix-glyphs.json` | Соответствие asset/frame/codepoint для проверки pack при загрузке |

Назначенные private-use glyphs занимают U+E000–U+F8FF в настроенном диапазоне. Исходные ширины остальных символов сохраняются. Если изменяемая страница содержит неназначенные исходные символы, сохраняются и её оригинальные pixels. Картинка вписывается в ячейку с сохранением пропорций. Старый renderer выводит глиф примерно в 8 пикселях; высота/ascent современного шрифта не дают произвольного масштаба на 1.12. Для крупной картинки нужен другой клиентский renderer.

Плагин получает официальный version manifest Mojang, находит 1.12.2 и скачивает client JAR с проверкой SHA-1. Из него извлекаются только файлы шрифта; client code/JAR не сохраняется в данных плагина. Кэш находится в `${storage.data-directory}/legacy-font/` относительно папки плагина. При отсутствии метрик и недоступном Mojang сборка даёт понятную ошибку и текстовый fallback; остальные модули продолжают работу. Повторная сборка после исправления шрифта создаёт графический pack.

Для ручного импорта откройте установленный официальным launcher файл `.minecraft/versions/1.12.2/1.12.2.jar` как ZIP, извлеките **`assets/minecraft/font/glyph_sizes.bin`** и загрузите его через «Исходный glyph_sizes.bin». Требуется ровно 65 536 байт. При необходимости исходных страниц их можно извлечь из того же JAR в кэш `legacy-font`. Не заменяйте оригинальные ширины нулями: это повреждает обычный Unicode. Minecraft-файлы шрифта не включены в JAR плагина или архив исходников.

Исходное расположение старых font assets описано в [Mojang/LegacyUnifont](https://github.com/Mojang/LegacyUnifont). На 1.13+ используется существующий генератор bitmap font JSON/atlas для формата соответствующей версии сервера. Картинки в игре включаются только после `SUCCESSFULLY_LOADED`; `ACCEPTED`/`DOWNLOADED` недостаточно. Отказ/ошибка загрузки оставляет текст.

## Текст и картинки на экране

Перетащите элемент или изображение в TITLE, SUBTITLE либо ACTION_BAR во вкладке «Экран». До 12 блоков можно включать отдельно, перемещать между позициями и удалять. Каждый имеет текст/fallback, статический режим, бегущую строку или до 32 кадров, скорость, ширину окна, промежуток, список миров и optional permission. Несколько активных блоков в одной позиции объединяются через пробел. В личных настройках есть отдельный переключатель «Экран».

Предпросмотр получает подстановки и причины скрытия от сервера; эскиз картинки показывает первый PNG-кадр. В игре загруженный pack даёт соответствующий глиф/GIF. Title обновляется без fade-in/fade-out; heartbeat продлевает время отображения. Action bar также обновляется по изменению/heartbeat; отключение очищает канал один раз.

На 1.13+ переключатель «Свободное размещение» включает собственный bitmap canvas через ресурс-пак: перетащите элемент на экран и настройте X/Y/размер. После изменения геометрии и применения создаётся соответствующая ревизия pack. На 1.12 свободного canvas нет; FREE_XY использует запасной текст action bar. Подробнее: [NATIVE-HUD.md](NATIVE-HUD.md). Для постоянных каналов нужен один владелец среди плагинов.

## Скорборд без пересоздания

Стабильные entry/teams и scores 15..1 сохраняют порядок, пустые и одинаковые строки. При первоначальной загрузке строки заполняются до установки SIDEBAR. Последующие изменения меняют текст и только добавленные/удалённые строки. Новые Bukkit-обёртки одного native objective распознаются как тот же objective; чужой sidebar сохраняет приоритет.

С [1.20.3](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-3) blank number format позволяет скрыть правые числа. Doctor показывает `scoreNumbers=blank/Paper` либо `blank/native` при успешном применении; `adapter-unavailable` требует проверки конкретного ядра. Для старых клиентов выберите «Панель без цифр»: собственный HUD на 1.13+ с pack либо TAB footer в 1.12/без pack. Обычная колонка старого SIDEBAR остаётся ограничением клиента. Плагин не скрывает глобальные цифры шрифта.

## Пределы проверки

Java/SQLite/HTTP и Chromium-тесты проверяют сохранение, старые texture pixels, отсутствие пересоздания на моделях Bukkit, native HUD вызовы, drag/touch и настоящие ZIP. Реальный Minecraft-клиент и live Spigot/Paper/Purpur не запускались. Загрузка шрифтов Mojang проверена через извлечение из synthetic JAR и подготовленный baseline; доступ к Mojang из среды сборки ограничен. Для выпуска на вашем сервере проверьте принятие/отказ pack, GIF, обновление и чужие display plugins. Подробности: [VALIDATION.md](VALIDATION.md).
