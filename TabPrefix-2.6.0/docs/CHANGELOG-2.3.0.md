# TabPrefix 2.3.0 — Суффиксы и оформление TAB

- Отдельный суффикс группы: свой текст/цвета/значки, прокрутка, кадры, cached LuckPerms suffix или скрытие; необязательный fallback для других групп.
- Цвет имени группы и общий анимируемый формат обычного TAB. `{suffix}`, `{display_name}`, `{tab_name}`, `{weight}` доступны в Studio; новые player cells используют общий формат.
- Приоритеты групп мышью, касанием, клавиатурой и кнопками. Сортировка по приоритету, весу LuckPerms, имени, группе, задержке или миру; обратный порядок.
- Сортировка обычного TAB через собственные scoreboard teams; учитывает видимость и чужое владение, очищает свои команды при отключении, показывает конфликты.
- Шаблон «Спокойный TAB» с мягкими цветами ролей и компактными Header/Footer. Использует реальные группы, сохраняет sidebar и боссбары.
- Личные переключатели суффиксов и сортировки; per-recipient имена и дифференциальная отправка, остановка анимации и восстановление отображения.
- Группы и веса читаются из кэша LuckPerms через защищённый read-only endpoint. Права и metadata в LuckPerms не изменяются.
- Сохранение/JSON-импорт/экспорт/RU/EN и обновление документов 2.1/2.2 без сброса. SQLite schema 3 и JSON schema 1 сохранены.

Инструкция: [TAB-SUFFIXES.md](TAB-SUFFIXES.md). Проверки и пределы: [VALIDATION.md](VALIDATION.md).
