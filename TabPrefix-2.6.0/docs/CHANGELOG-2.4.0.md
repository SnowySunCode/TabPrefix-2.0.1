# TabPrefix 2.4.0

- Добавлены адаптеры Minecraft 1.12.x–1.21.x и официальной серии 26.1–26.3, включая новую запись версии Paper/Purpur `build.N`.
- Native TAB поддерживает старые action packets и современные update/remove packets, дополнительные поля entry и новые immutable GameProfile. Оформление реальных игроков сохраняет их протокольные данные; виртуальный макет удаляет только собственные UUID.
- На 1.12 header/footer отправляются пакетами, sidebar использует совместимую регистрацию objective, prefix/suffix и заголовки соблюдают старые лимиты. RGB на 1.12–1.15 переводится в стандартные цвета. Графические assets сохраняются, но на 1.12 показывается текст.
- Resource pack получает формат версии сервера, включая `min_format`/`max_format` в новых клиентах. Смена версии пересобирает старую ревизию без перераспределения glyphs; несовместимый rollback отклоняется.
- Современный pack API использует UUID, фильтрует чужие ответы и снимает только собственные packs. Старые запросы продолжают отправляться последовательно. Добавлена обработка новых terminal statuses без преждевременного подтверждения загрузки.
- Редакторы RU/EN показывают ограничения версии. Применение оформления и личных настроек сразу переводит сообщение в состояние ожидания, чтобы старое уведомление об успехе не выглядело как результат текущего запроса.
- Заводской guard 1.16 расширяется автоматически, пользовательский диапазон сохраняется. Документы 2.1/2.2/2.3 читаются без новой миграции SQLite; существующие функции Studio сохранены.
- Добавлены тесты версий, метаданных ZIP, миграции pack, старых и новых API, десяти независимых пакетных контрактов и подсказок в реальном браузере. Фактические серверы и клиенты в среде сборки не запускались; пределы проверки перечислены в [VALIDATION.md](VALIDATION.md).

Установка: при остановленном сервере сохраните папку `plugins/TabPrefix`, замените единственный JAR и запустите сервер. Проверьте `/lptab doctor`. Матрица версий, Java и ограничения — [COMPATIBILITY.md](COMPATIBILITY.md).
