# Совместимость TabPrefix 2.6.0

Один JAR содержит адаптеры для Spigot, Paper и Purpur на Minecraft Java 1.12.x–1.21.x и 26.1–26.3. Официальная нумерация 2026 года — **26.x**, а не 1.26.x. Проверка версии принимает обычные Bukkit suffixes и новую запись Paper/Purpur `26.1.2.build.67-stable`, `26.3.build.157-beta`.

Это реализация совместимости, проверенная автоматическими тестами. Реальные серверы и Minecraft-клиенты в среде сборки не запускались. Проверка конкретного ядра, клиента и набора плагинов остаётся необходимой; подробности — [VALIDATION.md](VALIDATION.md).

Начиная с формата 69 используются `min_format` и `max_format` с major/minor. Пакет создаётся для версии сервера. При смене версии существующий active pack пересобирается из сохранённых assets, сохраняя UUID, назначения glyphs, документы оформления и базу. Откат к pack другого формата отклоняется: он не будет предложен клиенту как совместимый.

Матрица относится к уже известным форматам перечисленных серий. Будущие версии, snapshots, нестандартные форки, Folia и смешанные клиентские версии через ViaVersion не проверены. Сам по себе обход version guard не добавляет новый протокол или формат pack.

## Ограничения старых клиентов

- **1.12:** PNG/GIF используют Unicode-страницы с оригинальными метриками; один глиф отображается примерно в 8 пикселях. Современных bitmap font JSON в pack нет. Нужен исходный `glyph_sizes.bin` из клиента; плагин скачивает шрифты с Mojang либо принимает ручной импорт. До загрузки pack остаётся текст. Header/footer работают через пакетный адаптер. [Подробности](DREAM-TAB.md).
- **1.12:** team prefix и suffix ограничены 16 символами каждый, заголовок sidebar — 32; форматирование занимает часть лимита. На 1.13+ используются лимиты 64/128. Прокрутка и кадры продолжают работать в этих пределах.
- **1.12–1.15:** RGB и градиенты переводятся в ближайшие стандартные цвета. Сохранённый исходный документ не теряет RGB-настройки.
- **1.12:** Bukkit text fallback обычного TAB соблюдает лимит имени в 16 символов. При слишком длинном оформлении сохраняется обычное имя; пакетный адаптер использует компонент отображения.
- На 1.12 Bukkit не предоставляет чтение header/footer. Адаптер помнит собственные значения, но не может надёжно обнаружить пакетные изменения другого плагина. Для header/footer нужен один владелец. На новых API сохраняется проверка владения и восстановление прежних значений.

## Цифры sidebar и экран

| Режим | 1.12 | 1.13–1.20.2 | 1.20.3+ |
|---|---|---|---|
| Классический sidebar | Правые числа остаются | Правые числа остаются | Blank number format при доступном адаптере |
| Панель без цифр | TAB footer | Собственный HUD после загрузки pack; иначе TAB footer | Собственный HUD после загрузки pack; иначе TAB footer |
| Панель в TAB | Без чисел, видна при открытом TAB | То же | То же |
| Свободный экранный XY | Не реализован; стандартный action-bar fallback | Bitmap canvas с vanilla pack | Bitmap canvas с vanilla pack |

Нативное скрытие scores классического sidebar поддерживается начиная с [Minecraft 1.20.3](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-3). Плагин пробует Paper `NumberFormat.blank()`, затем доступный native setter. Режим HUD обходит числовую колонку собственным выводом и не заменяет глобально цифры шрифта. Это другой способ показа, не исправление renderer старого SIDEBAR.

FREE_XY реализован через private-use bitmap fonts и подписанные пробелы в action bar. Пак создаётся одним плагином; пользователь принимает его штатным Minecraft-диалогом. Координаты относятся к GUI, а не к физическим пикселям монитора. Масштаб GUI клиента меняет видимый размер. При крайнем смещении или очень широкой картинке используется более грубая растеризация, чтобы ячейка глифа поместилась в клиентскую шрифтовую текстуру. [Настройка и пределы](NATIVE-HUD.md).

TITLE/SUBTITLE/ACTION_BAR остаются доступными без pack с обычными клиентскими позициями. Постоянный action bar должен иметь согласованного владельца среди установленных плагинов.

## TAB и resource packs

Native TAB различает старые пакеты с action enum, пакеты обновления 1.19.3+ и отдельное удаление UUID. Обычное оформление меняет display name и сохраняет profile, game mode, listed, chat session/public key, list order и hat. Виртуальный макет создаёт 80 собственных UUID, копирует skin и удаляет только собственные записи. Современные записи поддерживают дополнительный порядок списка; реальные игроки не удаляются и их game mode не подменяется.

При недоступном packet adapter остаётся обычный TAB и Bukkit-текст. Полноценное оформление отдельно для каждого получателя в этом fallback не гарантируется. `/lptab doctor` показывает диагностику адаптеров обычного и фиксированного TAB.

На API с `addResourcePack` пакет получает стабильный UUID, ответы проверяются по ID, а прежний собственный pack снимается отдельно от чужих. На старом API используется `setResourcePack(url, hash)` и одна незавершённая отправка на игрока: новый pack ждёт ответа на предыдущий. Старые события без ID нельзя надёжно различить с одновременными отправками другого плагина. `DOWNLOADED` ещё не означает успешную загрузку; изображение включается после `SUCCESSFULLY_LOADED`.

## Java и установка

Байт-код плагина — Java 8. JVM для запуска выбирайте по требованиям конкретного серверного ядра, а не по target плагина. Рекомендации Paper:

| Сервер | Рекомендуемая Java |
|---|---|
| 1.12–1.16.4 | 11 |
| 1.16.5 | 16 |
| 1.17–1.19.x | 17 |
| 1.20–1.21.11 | 21 |
| 26.1+ | 25 |

Сборка плагина требует JDK 8+, отдельная пакетная тестовая матрица — JDK 17+ и Python 3. Node/Playwright/Chromium нужны только для браузерных тестов. Не используйте `/reload` для обновления JAR: остановите сервер, сохраните папку данных, замените JAR и запустите сервер полностью.

В `plugin.yml` намеренно отсутствует `api-version`, чтобы один файл загружался на 1.12. Новые ядра могут сообщить о legacy plugin; TabPrefix не использует Material/item/block API, требующий преобразования старых материалов. Runtime-зависимости изолированы, Bukkit, CraftBukkit, NMS, authlib и тестовые классы в итоговый JAR не включаются.

Заводской старый диапазон `1.16`–`1.16.5` расширяется при чтении настроек. Если диапазон был изменён администратором, он сохраняется. SQLite schema остаётся 3; обновление с 2.1/2.2/2.3 сохраняет оформление, суффиксы, боссбары, настройки игроков и графические assets.
