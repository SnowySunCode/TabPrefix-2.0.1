# Суффиксы, сортировка и оформление TAB — 2.4.0

## Быстрый старт

После замены JAR и полного запуска сервера откройте `/lptab design`. Выберите «Спокойный TAB», проверьте результат и нажмите «Применить к серверу». Шаблон включает обычный список, общий формат имён, сортировку по приоритетам и спокойные цвета ролей. Header показывает сервер, онлайн и мир; Footer — имя и задержку. Скорборд и боссбары сохраняются.

Шаблон загружает только уже существующие группы LuckPerms, по убыванию их веса. Для owner/admin/mod/helper/vip/mvp и распространённых английских вариантов выбираются мягкие цвета и небольшие значки. У default/player/user/member суффикс пустой, у других групп — `· {group}`. Это начальное оформление: название группы, цвет и суффикс можно изменить. Права, membership, префиксы и веса LuckPerms редактор не меняет.

## Группы и суффиксы

Во вкладке TAB нажмите «Загрузить группы LuckPerms» или «+ Группа». Повторная загрузка добавляет отсутствующие группы и сохраняет уже настроенные стили и их порядок. Ручная группа должна совпадать с названием группы LuckPerms; новая строка в Studio не создаёт permission group. Лимит — 64 стиля.

Выберите строку группы. Справа доступны свой цвет имени и три источника суффикса:

| Источник | Результат |
|---|---|
| Свой текст и анимация | Текст, &-цвета, MiniMessage, значки, подстановки, прокрутка или кадры |
| LuckPerms | Cached suffix пользователя с его текущими context/query options |
| Без суффикса | Скрывает и свой текст, и suffix LuckPerms для этой группы |

Кнопки добавляют готовый `[группа]`, значок или мир. Затем текст полностью редактируется. Перед непустым суффиксом добавляется один пробел, если он уже не задан. Пустой суффикс не оставляет разделитель. Общий переключатель отключает все суффиксы. «LuckPerms для остальных групп» управляет fallback для групп без собственной строки; явный источник LuckPerms работает независимо от этого fallback.

Анимация использует тот же редактор, что Header/Footer: окно 4–80 символов, шаг 0.1–10 секунд, до 32 кадров. Суффиксы и общий формат с анимацией обновляются раз в два тика независимо от медленного общего интервала. Это скорость в серверных тиках: при низком TPS анимация замедляется.

## Общий формат

Включите «Свой формат имён» и нажмите «Изменить формат». Начальный вариант — `{prefix}{display_name}{suffix}`. Например:

```text
{prefix}{display_name}{suffix} <dark_gray>·</dark_gray> <gray>{ping} ms</gray>
```

| Подстановка | Значение |
|---|---|
| `{player}` | Обычное имя игрока |
| `{display_name}` | Имя с цветом выбранной группы |
| `{prefix}` | Существующий текст/PNG/GIF-префикс с учётом resource pack получателя |
| `{suffix}` | Суффикс с цветами, анимацией и личной настройкой получателя |
| `{tab_name}` | Результат общего формата; используйте в PLAYER-ячейках фиксированного макета |
| `{weight}` | Вес выбранной группы LuckPerms, либо 0 |

Остальные подстановки Studio — группа, мир, онлайн, координаты, здоровье и другие — тоже доступны. Данные игрока/мира остаются буквальным текстом; metadata не исполняется как MiniMessage. `{suffix}` внутри собственного суффикса и `{tab_name}` внутри общего формата пустые: рекурсивное раскрытие не выполняется.

Общий формат применяется к обычному TAB. В фиксированном макете PLAYER-ячейка сохраняет свою строку: `{tab_name}` даёт общий формат, а свой шаблон даёт индивидуальное оформление ячейки. Новые PLAYER-ячейки используют `{tab_name}`; ранее сохранённые строки не переписываются.

Для суффикса над головой включите name tags и укажите `{suffix}` в поле «После имени». Выбранный цвет имени применяется через `{display_name}` в строках; реальное имя над головой сохраняется, team prefix/suffix настраиваются отдельно.

## Сортировка

Перетаскивайте группы за ⠿ мышью или касанием. Кнопки ↑ ↓ и стрелки клавиатуры тоже меняют приоритет. Выберите способ сортировки:

| Режим | Порядок |
|---|---|
| По порядку групп | Строки сверху вниз; неуказанные группы далее по весу, названию и имени |
| По весу LuckPerms | Больший вес выше, далее название группы и имя |
| По имени | Имя без учёта регистра |
| По группе и имени | Название группы, затем имя |
| По задержке | Меньшая задержка выше, затем имя |
| По миру и имени | Название мира, затем имя |

«Обратный порядок» переворачивает весь результат. Вес относится к группе, выбранной обычной настройкой `use-primary-group`; при её отключении берётся самая весомая inherited group. При одинаковых значениях имя и UUID стабилизируют порядок. Скрытые через `canSee` игроки не входят в список, число online или позиции макета.

«Сортировать обычный TAB» создаёт собственные teams для реальных игроков в личном scoreboard получателя. Name tags для этого включать не требуется. Чужие teams не меняются: при конфликте обычный TAB может сохранить порядок другого плагина, а Studio и `/lptab doctor` покажут `sortConflicts`. При отключении sorting собственные teams удаляются; если name tags остаются включены, их teams располагаются по имени.

В старых версиях Minecraft обычный клиент дополнительно помещает spectators после остальных игроков. Плагин не подменяет game mode. Фиксированный макет с PLAYER-ячейками использует заданный порядок позиций без этой группировки.

## Личные настройки и обновление

`/lptab settings` позволяет отключить свои суффиксы, серверную сортировку и анимацию. Суффиксы скрываются в шаблонах, использующих `{suffix}`; вручную вписанный в Header/Footer текст остаётся обычным текстом. Отключение сортировки использует порядок по имени в макете и освобождает собственную сортировку обычного списка. Другие получатели сохраняют свои настройки.

Формат и suffix отправляются отдельно каждому получателю через NativeTabAccess для 1.12–1.21.11/26.x. Версионные ограничения и пределы проверки — [COMPATIBILITY.md](COMPATIBILITY.md). При отказе этого адаптера остаётся глобальное текстовое Bukkit-оформление; разные личные настройки получателей и графика в таком fallback не гарантируются.

Документы 2.1/2.2 читаются без сброса: новый общий формат и сортировка обычного TAB выключены до выбора шаблона или явного включения. SQLite остаётся на схеме 3, JSON — на схеме 1. Экспорт включает всю конфигурацию, суффиксы и порядок групп. Импорт создаёт проверенный черновик; он применяется только после кнопки «Применить».
